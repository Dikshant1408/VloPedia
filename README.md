# ValoVault

ValoVault is a premium VALORANT companion platform built with Next.js 15, React 19, TypeScript, Tailwind CSS, Framer Motion, shadcn-style primitives, Prisma, PostgreSQL, Firebase, and React Query.

## What is included

- A polished marketing homepage with a VALORANT-inspired visual system
- SEO metadata, robots, and sitemap routes
- A reusable component foundation for future gameplay, inventory, and utility features
- Firebase and Prisma integration points for authenticated, data-driven expansion

## Getting started

1. Install dependencies.
2. Create a `.env.local` file from the variable names below.
3. Run the development server with `npm run dev`.

## Environment variables

- `NEXT_PUBLIC_SITE_URL`
- `DATABASE_URL`
- `NEXT_PUBLIC_FIREBASE_API_KEY`
- `NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN`
- `NEXT_PUBLIC_FIREBASE_PROJECT_ID`
- `NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET`
- `NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID`
- `NEXT_PUBLIC_FIREBASE_APP_ID`
- `FIREBASE_SERVICE_ACCOUNT`

## Scripts

- `npm run dev`
- `npm run build`
- `npm run start`
- `npm run lint`
